# 兼容性与证据

本文件只把有可重复证据的组合列为“已验证”。Manifest 最低版本声明不等于真实兼容性结论。

## 已验证组合

| 范围       | 组合                                                                     | 结论 | 证据                                                         |
| ---------- | ------------------------------------------------------------------------ | ---- | ------------------------------------------------------------ |
| 自动化仿真 | Windows `win32`、Node.js `v24.14.0`、内存 Photoshop 适配器、插件 `0.1.0` | 通过 | `npm run check`；`tests/stability.test.ts`；其余 Vitest 测试 |
| 生产构建   | Node.js `v24.14.0`、Webpack 5、ES2018 目标、Manifest v5                  | 通过 | `npm run build`；发布脚本校验清单和四个入口文件              |

`0.1.0` 的发布脚本会拒绝非 Windows、非 Node.js `v24.14.0` 或包含未提交改动的工作区。其他 Node.js 版本仍可用于开发和测试，但不属于当前可重复诊断归档的证据组合。

## 仅声明、尚未验证

- Manifest 声明 Photoshop 最低版本 `23.3.0` 和 UXP API v2；尚无任何真实 Photoshop 版本被列为兼容。
- Windows Photoshop、母版 PSD/PSB、字体、颜色配置和工厂输出组合尚未完成 M0。
- UXP Developer Tool 的真实加载、重启恢复和长时间运行仍需在 Issue #11 留存截图、日志和版本信息。
- macOS 未在产品范围内，也没有兼容证据。

增加兼容组合时，必须记录 Photoshop 完整版本、UXP Developer Tool 版本、Windows 版本、母版指纹、代表素材、输出配置和验收日期。没有这些证据不得把组合加入“已验证组合”。
