## 发布边界

- 发布标签和 ZIP 必须使用 `diagnostic` 或“诊断预发布”字样。
- 不得声称任何 Photoshop 版本已兼容，不得解除默认生产锁。
- 不得用内存适配器测试、截图或成功构建替代真实 PSD 与工厂验收。
- 外部证据完成后，需要单独评审生产服务接线、能力配置和兼容表，再决定生产版本号。

## 构建物

运行 `npm run release:build` 后生成：

该命令必须在 Windows、Node.js `v24.14.0` 和干净 Git 工作区运行；否则会拒绝生成无法准确追溯或无法复现字节的归档。

- `release/psd-piece-print-batch-v0.1.0-diagnostic/`：供 UXP Developer Tool 选择根目录 `manifest.json` 的待验收候选目录。
- `release/psd-piece-print-batch-v0.1.0-diagnostic.zip`：诊断预发布归档。
- 目录中的 `SHA256SUMS.txt`：归档内文件完整性清单。
- `evidence/AUTOMATED_EVIDENCE.json`：自动化证据索引和未完成外部证据。
- `evidence/TEST_REPORT.json` 与 `evidence/build/`：测试项目、源码提交及构建依赖锁定信息。
